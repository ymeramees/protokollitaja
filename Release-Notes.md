## Release Notes

### 0.9.4

- Show targets and shots in Protofinaal
- Use English as a base language instead of Estonian

### 0.9.3

- Support for Inband Scoring 5.0 added
- Fixes to 25m pistol events shot numbering and event namings
- Replace old URLs with protokollitaja.eu
- Tie-breaking updated to latest ISSF 2023 approved rules
- New help with quick start guide
- Linux and MacOS builds added
- Max team size increased to 18
- Added preliminary support for mixed teams finals in Protofinaal according to ISSF 2026 rules
- Added .xls export to Protofinaal
- Translation to Hungarian added
- Bunch of smaller bugfixes and improvements

### 0.9.2

- Finals can now again be started directly from Protokollitaja or finals file can be exported
- Finals file can now be imported to Protokollitaja and is embedded to the results page (can also be exported from there again)
- Air guns finals according to ISSF 2024 rules
- Logs now in Documents folder and settings location changed according to Windows requirements
- ProtoFinaal translated to English
- Improvements to logging
- Inner tens are included in export to xls file
- Translation to English improved
- Multiple smaller bugfixes
